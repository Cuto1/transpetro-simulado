# Transpetro — Reta Final

Aplicativo de estudo por questões para a prova da Transpetro.

- 3.500 questões mistas
- 2.500 específicas + 500 Português + 500 Inglês, com explicações completas da matéria após cada resposta
- calendário e treino diário
- histórico, revisão e pendências
- progresso salvo no navegador
- PWA instalável no celular
- funcionamento offline após o primeiro carregamento

## GitHub Pages
O projeto inclui um workflow para publicar automaticamente no GitHub Pages.

> Observação: o GitHub Pages é uma hospedagem estática. O progresso é salvo no navegador de cada aparelho. Sincronização entre aparelhos exige um backend.


## Redistribuição 2026
A partir de 19/10, o treino diário foi reequilibrado para se aproximar da estrutura da prova: 50 específicas, 10 Português e 10 Inglês nos simulados de 70 questões. Há reforço adicional de Sistemas de Informação, ESG, Governança/Riscos e Contratação, além de banco-reserva para revisão.
